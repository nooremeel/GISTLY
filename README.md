# Bookmark App

A full-stack bookmark manager with AI-assisted tagging/summaries (Google Gemini), built as a step-by-step learning project.

## Stack
- **Backend:** Node.js, Express, MongoDB (Mongoose)
- **Frontend:** React
- **Auth:** JWT (httpOnly cookies)
- **AI:** Google Gemini API (backend-only)

## Setup
1. Copy `.env.example` to `.env` in the root (or `/backend`, depending on where it's loaded) and fill in real values.
2. `cd backend && npm install`
3. `cd frontend && npm install`
4. See individual task docs in `PROJECT_PLAN.md` for build progress.
